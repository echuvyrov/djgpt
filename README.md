# AI DJing App

An AI-powered DJing application that creates and mixes playlists based on user prompts.

## Features

- AI-powered playlist generation
- BPM matching and mixing
- Clean content filtering
- Editable playlists
- Integration with Spotify

## Setup

1. Create a `.env` file with your Spotify credentials:
```
SPOTIFY_CLIENT_ID=your_client_id
SPOTIFY_CLIENT_SECRET=your_client_secret
```

2. Install dependencies:
```
pip install -r requirements.txt
```

3. Run the application:
```
python app.py
```

## Usage

1. Start the application
2. Go to http://localhost:8000
3. Enter your playlist prompt
4. The AI will generate and mix your playlist
